# 開口啦

一個以廣東話設計、幫怕同陌生人講嘢嘅人逐步建立完整句子同社交信心嘅 Expo 手機應用。

## 核心體驗

- 今日：每日兩分鐘練習、連續日數、信心值同下一個小任務
- 快練：仿短片節奏嘅 15 秒垂直回應卡
- 練句：由簡短回應加上想法或原因，再錄音及重聽
- 出街：三階段低壓現實任務，每個任務都有簡易版本
- 旅程：成長階段、成就、練習紀錄同可清除嘅本機進度

所有進度只儲存在裝置本機。錄音只用作即時重聽，不會上載。

## 本機預覽

```bash
npm install
npm start
```

用 Expo Go 掃描畫面上嘅 QR code，或者按 `a` 開 Android 模擬器。

## 驗證

```bash
npm run typecheck
npm run build
```
